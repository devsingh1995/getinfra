About Microsoft Azure

Microsoft Azure, launched in February 2010 and headquartered in Redmond, Washington, is the world's second-largest cloud platform with ~21% global market share and $75 billion+ in annual revenue (FY2025). It is the cloud of choice for enterprises - 95% of Fortune 500 companies use Azure, and it serves 350,000+ organizations worldwide through 70+ global regions and 400+ data centres. No other cloud provider has more regions globally.

For Indian customers, Azure has the deepest India presence of any hyperscaler: four regions in India - Central India (Pune), South India (Chennai), West India (Mumbai), all launched in 2015 - plus India South Central (Hyderabad), expected in 2026 as part of Microsoft's $3 billion India AI infrastructure investment. Pune has full Availability Zone support (3 AZs), making it Azure's primary India region for high-availability production workloads.

Azure's defining advantage over AWS and GCP is its enterprise ecosystem integration. For organizations already using Microsoft 365, Teams, Active Directory, SQL Server, Windows Server, and Power BI, Azure is the natural cloud - workloads migrate with minimal friction, and Azure Hybrid Benefit lets enterprises bring existing Windows and SQL Server licences to the cloud, reducing VM costs by up to 85% compared to fully licensed rates.

On AI, Azure has placed the biggest bet: a $13 billion strategic partnership with OpenAI gives Azure customers exclusive access to GPT-4, GPT-4o, o3, and other OpenAI models via Azure OpenAI Service - integrated with Microsoft 365 Copilot, GitHub Copilot, and the rest of the Microsoft stack. Azure now has 60,000+ AI customers and 11,000+ AI models available through Azure AI Foundry. H100 GPU (ND H100 v5) is available in several regions including India (Central India / Pune).

⚠️

Watch-outs for Indian teams

  • USD billing - no INR pricing, no UPI/NEFT; GST requires separate Azure India billing entity setup; same forex risk as AWS and GCP
  • Not MeitY empanelled - ineligible for Indian government and PSU procurement without separate assessment
  • Complex VM naming convention - Standard_D4s_v5, Standard_NC40ads_H100_v5 etc. are notoriously cryptic; steep learning curve vs GCP or DO
  • Egress charges - outbound data to internet charged at $0.087/GB after 5 GB/month free; adds up significantly for data-heavy workloads
  • GPU pricing premium - Azure H100 8-node cluster costs ~₹38.6L/month; Indian providers (E2E, Cyfuture) offer H100 at 10-15× lower cost
  • Stopped VM still bills for storage - deallocated VMs don't bill for compute, but managed disk and OS disk keep billing ($2-50/mo each)
  • Support tiers are expensive - Developer support $29/mo; Standard $100/mo; Professional Direct $1,000/mo; needed for production SLAs
  • India region service gaps - not all Azure services are available in all India regions; some services lag Central India (Pune) by months or years

VM Pricing - India Regions

All prices in USD per month, Linux, Pay-As-You-Go. India regions (Central, South, West) are typically priced similarly to each other and ~10-15% above East US rates. Managed disk billed separately. Per-second billing, 1-minute minimum.

Pay-As-You-Go

Full price, no commitment. Per-second billing (1-min min). Best for unpredictable workloads, dev/test, and short-lived VMs.

📋 Reserved Instances (RI)

Up to 72% off for 1-3 year commitments. Combine with Azure Hybrid Benefit for up to 85% savings on Windows workloads.

⚡ Spot VMs

Up to 90% off PAYG. Eviction with 30s notice. Best for ML training with checkpointing, batch jobs, and stateless workloads.

Common questions

Microsoft Azure GPU FAQs

What GPUs does Microsoft Azure offer?

Azure offers GPU VM families using NVIDIA H100, H200, A100, RTX PRO 6000, A10, T4, GB200 and V100 accelerators, along with AMD MI300X systems. Availability varies by VM series and region.

How much does an Azure GPU VM cost?

Pricing varies by VM size and region. Example pay-as-you-go rates range from about $0.53 per hour for a one-GPU T4 VM to more than $100 per hour for large H200 or GB200 multi-GPU systems.

Does Azure offer Spot GPU VMs?

Azure Spot Virtual Machines can use unused capacity at a discount, but support depends on the VM size and region. Spot VMs can be evicted with short notice and do not provide an availability SLA.

Can Azure GPU VMs be reserved?

Azure offers one-year and three-year Reserved VM Instances for eligible VM sizes and subscriptions. Eligibility and savings vary by region, VM series, agreement and market.

Which Azure GPU VM is best for LLM training?

ND-series GB200, H200 and H100 systems target large distributed training. A100 and single-GPU H100 VMs may be more practical for smaller training, fine-tuning and applied-AI workloads.

Does Azure offer GPU VMs in India?

Azure lists regions in Pune, Hyderabad, Chennai and Mumbai. However, each GPU VM family has its own regional availability, so confirm the exact SKU before deployment.

Are the prices on this page guaranteed?

No. Azure prices vary by region, currency, operating system, subscription and agreement. Use the official Azure Pricing Calculator to confirm the final estimate.
