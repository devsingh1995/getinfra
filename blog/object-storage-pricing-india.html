Object Storage Pricing in India: Storage, Requests, Egress and GST Compared

Daya Shankar
September 1, 2026
13 min read

Quick Answer: Object storage cost is not just the advertised price per GB. The real bill can include storage capacity, API requests, retrieval charges, minimum storage periods, internet egress and GST. For backup-heavy workloads, capacity may dominate. For SaaS, media, AI and data-platform workloads, requests and outbound transfer can matter just as much.

Object storage pricing looks simple when the first number on the page is ₹1 per GB or $0.02 per GB.

The difficulty starts when the storage is actually used.

Applications upload millions of objects. Users download files. Archived data gets restored. AI datasets move between environments. Lifecycle rules shift objects between storage classes.

Each activity can create a different billing meter.

A better starting equation is:

Object Storage TCO = Storage + API Requests + Retrieval + Data Transfer + Protection + Applicable Taxes

For Indian buyers, the last part matters too. A provider billed in USD and a provider billed in INR can have very different invoice treatment even when their raw infrastructure rates look similar.

If you first need to decide whether object storage is the right storage model at all, read the Object Storage vs Block Storage vs File Storage guide.

Pricing note: Provider pricing and tax documentation referenced in this article were checked on 1 September 2026. Cloud pricing can vary by region, storage class, currency, account type and tax status. Always verify the current provider page before purchasing.

Why Price Per GB Is Not Enough

Consider two workloads that both store 10 TB.

Workload A: Backup Repository

The organization:

  • Stores 10 TB
  • Adds a relatively small number of large backup files
  • Restores only 100 GB in a normal month
  • Rarely serves data directly to users

For this workload, capacity and archive/retrieval pricing are likely to matter most.

Workload B: SaaS Media Platform

The organization:

  • Stores the same 10 TB
  • Creates millions of objects
  • Performs frequent GET and LIST operations
  • Delivers several terabytes to users every month

The stored capacity is identical.

The economics are not.

This is why object storage should be priced around the access pattern, not just the bucket size.

The 2026 Flexera State of the Cloud Report found that managing cloud spend remains a top challenge for 85% of respondents, while estimated wasted IaaS and PaaS spend increased to 29%.

For a broader look at charges that can sit outside headline cloud prices, see the Cloud Pricing Hidden Costs in India guide.

Small API Requests Become Large Bills at Scale

Individual API requests are usually inexpensive.

Millions or billions of requests are different.

Common object-storage operations include:

  • PUT: Upload or replace an object
  • GET: Retrieve an object
  • LIST: Inspect objects in a bucket or prefix
  • COPY: Copy an object
  • DELETE: Remove an object
  • Lifecycle transitions: Move objects between storage classes

Request pricing matters less when a workload stores a few large backup archives.

It matters much more for workloads such as:

  • Image and thumbnail platforms
  • Application logs
  • RAG document chunks
  • AI artifacts
  • Model files
  • Data lakes
  • Millions of small customer uploads

The 2026 Komprise State of Unstructured Data Management Report found that 74% of surveyed enterprise storage leaders manage more than 5 PB of unstructured data, while 40% manage at least 10 PB.

At that scale, object count and access frequency become financial architecture decisions.

Before choosing a service, estimate:

  1. How many objects will be created each month?
  2. How many PUT, GET and LIST operations will the application generate?
  3. Are objects mostly large or very small?
  4. Will lifecycle rules create additional transition operations?

Egress Is Often the Biggest Surprise

Egress is data leaving the provider or cloud environment.

Object storage can generate egress through:

  • Customer downloads
  • Backup restores
  • Data migrations
  • CDN origin traffic
  • Multi-cloud transfers
  • AI dataset movement
  • Application-to-user delivery

Different providers handle this very differently.

AWS S3

AWS S3 pricing includes the first 100 GB per month of applicable data transfer out to the internet at no charge, aggregated across AWS services and regions except excluded regions such as China and GovCloud.

Additional internet transfer is billed according to AWS data-transfer tiers and region.

That means a workload with modest downloads can behave very differently from one serving several terabytes each month.

Cloudflare R2

Cloudflare R2 pricing does not charge for R2 egress bandwidth to the internet.

R2 still charges for:

  • Stored data
  • Class A operations
  • Class B operations
  • Retrieval from Infrequent Access storage

Other Cloudflare products used alongside R2 can have their own pricing, so “free egress” should not be interpreted as “the entire application delivery path is free.”

DigitalOcean Spaces

DigitalOcean Spaces currently starts at $5/month and includes:

  • 250 GiB storage
  • 1 TiB outbound transfer

Additional standard storage is $0.02/GiB, while additional outbound transfer is $0.01/GiB.

This bundled model can be easier to estimate for smaller web, media and application workloads.

Backblaze B2

Backblaze B2 currently starts at $6.95/TB/month.

Its published model includes free egress up to 3× the average monthly data stored. Standard overage beyond that allowance is listed at $0.01/GB, while several CDN and compute partners have different egress arrangements.

AceCloud Object Storage

AceCloud S3 pricing publishes INR pricing for Standard, Infrequent Access and Glacier-style storage classes in Noida.

Its current object-storage pricing page also lists:

  • First 100 GB/month outbound: Free
  • Additional internet data transfer: ₹4.30/GB

For India-hosted workloads, the useful comparison is not simply AceCloud versus one hyperscaler. It is whether the combination of storage, requests, egress, region and invoice structure fits the workload better than the available alternatives.

The Better Egress Question

Do not ask only:

How much does 1 TB cost to store?

Also ask:

How much does 1 TB cost to deliver to users or move out of the platform?

For backup archives, storage capacity may dominate.

For video, downloads, CDN origins, software distribution or AI datasets, cost per TB delivered can be more useful than cost per TB stored.

Cold Storage Is Cheap Until You Retrieve It

Archive and infrequent-access tiers are designed for data that is not accessed frequently.

They can reduce storage-at-rest cost significantly.

But lower capacity pricing can come with:

  • Retrieval charges
  • Restore operations
  • Minimum storage periods
  • Minimum billable object sizes
  • Lifecycle transition charges
  • Slower restore times

For example, AceCloud currently publishes a 30-day minimum duration and 128 KB minimum billable object size for its Standard-Infrequent Access class.

Other cloud providers use similar concepts across archival tiers, although the exact duration and minimum size vary.

Before moving data to a colder tier, estimate:

QuestionWhy It Matters
How often will data be restored?Frequent retrieval can remove the storage savings
How much data is restored at once?Retrieval fees grow with restore volume
How quickly is it needed?Faster archive retrieval can cost more
Is there a minimum storage duration?Early deletion can still be billed
Is there a minimum billable object size?Millions of tiny objects can cost more than expected
Do lifecycle transitions cost money?Moving data between classes can create request charges

The cheapest archive tier is not always the cheapest place for data that becomes active again.

GB vs GiB Can Also Change the Calculation

Cloud storage pages do not always use exactly the same unit.

You may see:

  • GB
  • GiB
  • TB
  • TiB

A GiB is larger than a decimal GB, and a TiB is larger than a decimal TB.

The difference is small at low capacity but becomes more noticeable at tens or hundreds of terabytes.

When comparing two providers, normalize the unit before calculating the monthly bill.

Do the same for:

  • Per-1,000 vs per-million requests
  • GB vs GiB egress
  • Monthly average storage vs peak storage
  • Decimal TB vs binary TiB

This avoids comparisons where the spreadsheet looks exact but the underlying units are different.

GST Belongs in the Cloud Cost Model

For Indian organizations, tax treatment should be included before declaring one provider cheaper.

AWS India

AWS India tax guidance states that GST applies to cloud services sold by AWS India.

AWS currently charges:

  • 9% CGST + 9% SGST for applicable customers in Delhi
  • 18% IGST for applicable customers in other Indian states

Registered business customers should maintain the correct GSTIN and billing address to support proper tax invoicing and any eligible input-tax treatment.

DigitalOcean

DigitalOcean’s India tax documentation states a current GST rate of 18% for customers with a tax location in India.

Business customers with a valid GSTIN can add it to their account. DigitalOcean notes that this removes the tax charge from the invoice but the customer remains subject to the applicable reverse charge mechanism.

Tax treatment depends on the provider, billing entity, GST registration and customer circumstances.

This article is not tax advice. Confirm the accounting treatment with your finance or tax team.

What Changes at 1 TB, 10 TB and 100 TB?

Different cost components become more important as storage grows.

ScaleWhat to Watch Most Closely
1 TBBase package, included transfer, request allowance, minimum commitment
10 TBRequest volume, egress, lifecycle rules, retrieval behaviour
100 TBVolume discounts, request scale, egress, archive policy, migration cost, contract terms
Petabyte scaleCustom pricing, data movement, operations, lifecycle automation, retrieval, support and exit strategy

At 1 TB, a bundled storage product can be easy to budget.

At 100 TB, a small difference in capacity rate matters much more—but so can moving several terabytes out every month.

The correct optimization metric depends on the workload.

That is why generic “cheapest object storage” rankings should be treated carefully.

How to Compare Object Storage Providers

Before shortlisting a provider, collect these values.

Storage

  • Standard storage price
  • Infrequent-access price
  • Archive price
  • Volume tiers
  • Minimum billable object size
  • Minimum storage duration

Requests

  • PUT / write price
  • GET / read price
  • LIST price
  • Lifecycle transition price
  • Delete or special-operation pricing
  • Free request allowance

Retrieval

  • Standard retrieval
  • Expedited retrieval
  • Archive restore
  • Retrieval time
  • Restore retention period

Networking

  • Internet egress
  • Included outbound allowance
  • Same-region transfer
  • Cross-region transfer
  • CDN integration
  • Private endpoint pricing

Commercial and Tax

  • INR or USD billing
  • GST treatment
  • GST invoice availability
  • Commitment requirements
  • Support pricing
  • Volume discounts

The Cloud Provider Selection Checklist for India can be used for the broader provider evaluation after storage economics have been modeled.

A Simple Object Storage TCO Formula

For a first-pass estimate, use:

Monthly Object Storage TCO =

Stored GB × Capacity Rate

+ PUT/GET/LIST Requests

+ Retrieval Charges

+ Outbound Transfer

+ Replication / Lifecycle Costs

+ Backup or Protection Add-ons

+ Applicable Taxes

For larger environments, also include:

  • Migration cost
  • Engineering time
  • CDN
  • Private connectivity
  • Support
  • Monitoring
  • Data deletion or early-deletion penalties

The goal is not to create a perfectly accurate forecast on the first attempt.

The goal is to make sure no major cost meter is missing.

FAQs

What is the biggest hidden cost in object storage?

For many active workloads, outbound data transfer is one of the largest hidden costs. For archive-heavy workloads, retrieval charges and minimum storage durations can also matter. Request pricing becomes important when applications create or read millions of small objects.

Are object storage API requests expensive?

Individual requests are usually inexpensive, but request cost can become meaningful at very high volume. Workloads with millions or billions of PUT, GET or LIST operations should include request pricing in their model.

Is Cloudflare R2 really free for egress?

Cloudflare does not charge R2 internet egress bandwidth fees. R2 still charges for storage and operations, and Infrequent Access storage has retrieval charges. Other Cloudflare products used in the delivery path may have separate pricing.

How much outbound transfer does DigitalOcean Spaces include?

DigitalOcean Spaces Standard currently includes 1 TiB of outbound transfer in its $5 monthly base package, along with 250 GiB of storage. Additional outbound transfer is listed at $0.01/GiB.

Does AWS S3 include free data transfer?

AWS currently includes the first 100 GB per month of applicable data transfer out to the internet across AWS services and regions, with stated exclusions. Additional internet transfer is billed according to AWS pricing.

Does object storage attract GST in India?

Cloud services can be subject to 18% GST in India, but the invoice treatment depends on the provider, billing entity, customer GST registration and transaction structure. Registered businesses should verify GSTIN and reverse-charge requirements with their finance or tax team.

Is cold object storage always cheaper?

No. Cold and archive tiers can reduce storage-at-rest pricing, but retrieval charges, minimum storage periods and lifecycle operations can make frequently accessed data more expensive overall.

Which object storage provider is cheapest in India?

There is no universal cheapest provider. The result changes with stored capacity, request volume, retrieval frequency, egress, region, billing currency and GST treatment. Price the actual workload rather than ranking providers only by GB-month.

Final Takeaway

Do not price an empty bucket.

Price the workload that will use it.

For object storage, calculate:

Capacity + Requests + Retrieval + Egress + Protection + Tax

Then decide which meter matters most.

If data mostly sits untouched, optimize storage capacity.

If applications touch millions of objects, model API requests.

If large datasets move regularly, prioritize egress.

If data goes into cold tiers, calculate retrieval and minimum-duration charges.

And if the service is being purchased in India, compare the final invoice rather than stopping at a USD or INR list price.
