Windows Cloud Server Pricing in India: VM, License, Storage and Backup Costs

Daya Shankar
September 6, 2026
18 min read
Windows cloud server pricing is usually more complex than Linux because the final bill can include VM compute, Windows Server licensing, storage, backup, RDS CALs, SQL Server, networking and tax. The cheapest VM configuration is not necessarily the cheapest Windows workload once these layers are added.
Quick Answer: A Windows cloud server in India should be priced as a complete workload, not just a VM. The main cost layers are compute, Windows Server licensing, persistent storage and backup. Multi-user Remote Desktop Services, SQL Server, public IPs, internet egress, managed support and GST can add further cost. Compare the final monthly TCO using the same vCPU, RAM, disk, backup, licensing and network assumptions across providers.

Two cloud providers can advertise Windows VMs with the same vCPU and RAM and still produce very different monthly bills.

The reason is simple.

A Windows workload can include several independent cost layers:

Windows Cloud TCO: VM Compute + Windows Server License + Storage + Backup + Optional RDS + Optional SQL Server + Networking + Support + Applicable Taxes

Some providers bundle the Windows operating-system license into the VM rate.

Others show it as a separate premium image or software charge.

Storage may be included in one plan and separately billed in another.

Backup may be charged by protected GB, snapshot size or retained copies.

A business application used by multiple employees may also require Remote Desktop Services licensing.

That is why a headline VM price should be treated as the starting point, not the final Windows server cost.

For the wider cloud-cost model, see Cloud Pricing Hidden Costs in India.

Pricing note: Public provider and Microsoft licensing information in this article was checked on 6 September 2026. Windows licensing rights, VM rates, backup prices and tax treatment can change by provider, region, tenancy model and customer agreement. Verify current commercial terms before purchasing.

What Determines Windows Cloud Server Pricing in India?

The major cost components are:

Persistent storageGB, disk class, IOPS, throughputOS and application data remain billable

A useful comparison keeps all of these assumptions identical across providers.

Do not compare a Windows VM with 100 GB SSD and backup against another provider’s bare compute-only VM.

How Much Does the Windows Server License Add?

There is no single universal cloud Windows Server surcharge.

Providers package the license differently.

Google Cloud gives one of the clearest public reference points.

For most Compute Engine machine types using a Google-provided Windows Server image, Google currently charges:

$0.046 per visible vCPU per hour

in addition to the underlying VM resources.

Using a 730-hour month:

Visible vCPUsWindows Server Premium / HourApprox. Windows Premium / 730 Hours
1$0.046$33.58
2$0.092$67.16
4$0.184$134.32
8$0.368$268.64
16$0.736$537.28

This is a Google Cloud pricing example, not a universal Windows Server rate.

AWS packages Microsoft Windows into its Windows Usage instance pricing. AWS also documents that using Optimize CPUs on eligible license-included Windows instances can save $0.046 per vCPU-hour in Windows Server licensing cost when the visible vCPU count is reduced.

Azure presents Windows Server through Windows VM pricing and also supports Azure Hybrid Benefit for eligible licenses.

Important: Never copy one provider's Windows surcharge into a comparison spreadsheet and assume every cloud uses the same license rate. Compare the complete Windows VM price for each provider.

Is the Windows Server License Included in the VM Price?

Sometimes.

The most common models are:

Licensing ModelHow It WorksWhat to Check
License includedWindows Server is already built into the VM priceWhether the listed price is Windows or Linux
Premium image / software chargeWindows license is added to base computePer-vCPU or per-instance premium
Eligible BYOL / hybrid benefitExisting rights reduce or replace part of the license chargeMicrosoft eligibility and cloud-specific rules
Bundled managed planCompute, Windows and sometimes additional software/support are bundledWhat exactly is included

AWS

AWS EC2 Windows Usage prices include the cost of eligible Microsoft Windows Server licensing in the Windows instance rate.

The Windows rate should therefore be compared against the equivalent Linux instance rather than treated as pure compute.

Google Cloud

Google Cloud explicitly treats Windows Server as a premium image.

For most machine types, the published premium is currently $0.046/hour for each visible vCPU.

Azure

Azure publishes separate Windows VM pricing.

Customers with qualifying Windows Server licenses covered by active Software Assurance or eligible subscription licenses may be able to use Azure Hybrid Benefit and pay a lower VM rate.

Azure states that Hybrid Benefit can be combined with other savings mechanisms such as reservations or savings plans where eligible.

The important comparison is:

Windows PAYG price versus eligible bring-your-own-license or hybrid pricing for the same VM.

Can You Bring an Existing Windows Server License to the Cloud?

Sometimes, but portability should never be assumed.

Microsoft licensing rights depend on factors such as:

  • License type
  • License edition
  • Software Assurance
  • Subscription rights
  • Cloud platform
  • Dedicated versus shared infrastructure
  • Outsourcing terms
  • Product version
  • Existing commercial agreement

Azure Hybrid Benefit is a specific Microsoft entitlement for eligible Windows Server and SQL Server licenses on Azure.

Other cloud environments can have different rights and restrictions.

Do not make a cloud purchasing decision based on the assumption that an existing on-premises Windows Server license can automatically be moved to any shared public-cloud VM.

Check the Microsoft Windows Server licensing guidance and the current Microsoft Product Terms for the customer’s agreement.

Windows Server vs RDP vs RDS CAL

These terms are often mixed together, but they describe different things.

TermWhat It IsMain Cost Question
Windows ServerServer operating systemIs the OS license included?
RDPRemote Desktop ProtocolConnection technology itself
Remote Desktop ServicesWindows Server role for multi-user/session applicationsDoes the deployment use RDS functionality?
RDS CALUser or device access license for RDSHow many licensed users/devices are required?
SQL ServerMicrosoft database softwareWhich SQL edition and licensing model apply?

Administrative RDP Is Not the Same as Multi-User RDS

Microsoft licensing guidance allows limited Remote Desktop access for server administration without purchasing RDS CALs.

That should not be confused with using a Windows Server VM as a shared desktop or application environment for employees.

Microsoft states that each user or device accessing Remote Desktop Services generally needs an appropriate RDS CAL.

RDS CALs can be licensed:

Per User Per Device

The better option depends on whether people use multiple devices or multiple people share the same device.

This distinction matters for common business workloads such as:

  • ERP
  • Accounting applications
  • Tally environments
  • Shared line-of-business software
  • Hosted Windows applications
  • Session-based desktops

Do not treat ordinary administrative RDP access as permission to host unlimited employee desktops.

Does SQL Server Cost Extra?

Usually, yes.

Windows Server and SQL Server are separate Microsoft products.

A Windows VM does not automatically include SQL Server.

Google Cloud’s public licensing table is a useful example of how large this additional software layer can become.

Google currently lists SQL Server image premiums of approximately:

SQL Server EditionPublished Google Cloud License Rate
SQL Server Enterprise$0.399 per core/hour
SQL Server Standard$0.120 per core/hour
SQL Server Web$0.011 per core/hour
SQL Server ExpressNo additional SQL license charge

Google states that SQL Server licensing is charged in addition to the Windows Server image and underlying VM.

It also applies a minimum four-core licensing requirement to SQL Server instances.

That means a small VM can still carry four cores of SQL licensing.

This is one reason a Windows database workload can cost much more than a plain IIS or .NET application server.

Indian Provider Pricing Can Use a Different Bundling Model

Indian cloud providers may package Windows software differently from hyperscalers.

Two current examples illustrate why buyers should compare the complete bundle rather than one software component.

E2E Cloud

E2E documents minimum billing for services involving third-party software licenses.

Its current example states that a CW.10GB Windows node costs ₹3.3/hour, but launching a Windows machine creates a minimum billing amount to cover the third-party license.

This is different from simply multiplying an hourly VM rate by usage.

For short-lived Windows workloads, minimum-license billing can materially affect economics.

AceCloud

AceCloud currently publishes dedicated Windows SQL Cloud bundles in Noida.

Example public plans include:

PlanvCPUsRAMPublished Monthly Price
WM-SQL.30430 GB₹51,250
WM-SQL.601260 GB₹77,900
WM-SQL.901690 GB₹102,500

These should not be compared directly with a plain Windows VM because the product is positioned as a Windows SQL Cloud service.

The example is useful because it shows how Indian providers may bundle Windows, SQL-related software and infrastructure into one commercial SKU rather than exposing the same line-item model as AWS, Azure or Google Cloud.

Comparison rule: A bundled Windows SQL plan, a plain Windows VM and a BYOL Windows VM are different products. Normalize software, storage, backup and network assumptions before comparing price.

How Much Do Storage and Backup Add?

Windows Server workloads still need the same storage planning as Linux workloads.

Persistent Storage

Persistent disks may be billed separately from the VM.

Pricing can depend on:

  • Capacity
  • SSD, NVMe or HDD
  • Provisioned IOPS
  • Throughput
  • Redundancy
  • Snapshots
  • Region

For databases and transaction-heavy Windows applications, disk performance can matter as much as capacity.

If you are deciding between storage models, see Object Storage vs Block Storage vs File Storage.

Backup

Backup cost is driven by different variables:

  • Amount of protected data
  • Daily change rate
  • Backup frequency
  • Retention period
  • Number of recovery points
  • Compression/deduplication
  • Archive tier
  • Restore charges
  • Cross-region copy
  • Network transfer

A 200 GB system disk does not necessarily create exactly 200 GB of long-term backup cost.

Retention can multiply stored recovery data.

Snapshot vs Backup: Are They the Same?

No.

A snapshot records the state of a disk or volume at a point in time.

A backup strategy is broader.

It should answer:

  • How many recovery points exist?
  • How long are they retained?
  • Can ransomware or administrators delete them?
  • Are copies stored independently?
  • How quickly can data be restored?
  • Has the restore process been tested?

Snapshots can be part of a backup strategy.

They should not automatically be treated as the entire strategy.

For older retention copies, Cloud Archive Storage in India explains the trade-off between lower storage price and slower or more expensive retrieval.

What Does a Complete Windows Server Bill Include?

Assume an organization needs a 4 vCPU, 16 GB Windows business server.

The quote should include at least:

Cost LayerWhat to Verify
VM4 vCPU, 16 GB RAM, region and machine family
WindowsIncluded, separate premium or eligible BYOL
OS diskCapacity and disk performance tier
Data diskApplication/database storage requirement
BackupProtected GB, frequency and retention
RDSRequired users or devices
SQL ServerEdition and core count if used
Public IPIncluded or separately billed
Internet egressFree allowance and paid tiers
NAT / load balancerAny per-hour or per-GB processing
SupportIncluded or additional plan
GSTInvoice treatment and final tax amount

The same 4 vCPU / 16 GB specification can therefore produce very different total costs.

Monthly Windows TCO Worksheet
  • VM compute: ₹ / $ per month
  • Windows Server: Included or additional
  • Persistent storage: OS + application disks
  • Backup: Protected data × retention model
  • RDS: Licensed users/devices if applicable
  • SQL Server: Edition/core licensing if applicable
  • Networking: IP + NAT + egress + load balancer
  • Support: Required plan
  • Tax: Applicable GST treatment

That number is more useful than the VM’s hourly price.

GST Can Change the Final India Invoice

Indian buyers should compare the invoice after tax treatment.

AWS India currently states that cloud services sold by AWS India to Indian customers are subject to GST.

For customers in Delhi, AWS India charges:

  • 9% CGST
  • 9% SGST

For customers in other Indian states, it charges:

  • 18% IGST

Google Cloud’s India tax treatment can vary by contracting entity and GSTIN status.

Google currently states that customers in India contracted with Google Asia Pacific can be charged 0% India GST when a valid GSTIN is supplied, while customers without a valid GSTIN are charged 18%. Services sold by Google Cloud India Private Limited are subject to 18% India GST regardless of GSTIN status.

This is why USD list price should not be converted to INR and treated as the final invoice.

For more detail, see the INR vs USD Cloud Billing Guide.

Do You Keep Paying When a Windows VM Is Turned Off?

Potentially.

This depends on provider state semantics.

Azure is a good example.

Microsoft distinguishes between:

  • Stopped
  • Stopped (Deallocated)

A VM that is only Stopped can continue to incur compute charges because the underlying host resources remain allocated.

A Deallocated VM does not incur the VM compute charge.

However, Microsoft notes that resources such as disks and some networking components can continue billing after deallocation.

The same general principle appears across cloud providers:

Stopping compute does not automatically delete persistent resources.

Possible continuing charges include:

  • Managed disks
  • Snapshots
  • Backup
  • Reserved/static IPs
  • Load balancers
  • Software minimums
  • Committed-use plans

Always check what the provider means by “stop.”

Networking Is Part of Windows TCO Too

A Windows server used only by internal administrators may generate little outbound traffic.

A public IIS application, remote desktop environment or file-serving workload can generate much more.

Potential network costs include:

  • Internet egress
  • Public IP
  • NAT Gateway
  • Load balancer
  • Cross-zone traffic
  • VPN
  • Private connectivity

The Cloud Egress Costs in India article covers why these charges can become large at multi-terabyte scale.

For RDS-style workloads, bandwidth should also be tested from the locations where users actually work.

Latency affects the usability of interactive remote sessions even when bandwidth cost is low.

How Can You Reduce Windows Cloud Server Cost?

Cost optimization has two parts.

Use Less

Rightsize CPU and RAM, shut down non-production systems, remove unused disks, reduce unnecessary backup retention and clean up stale snapshots.

Pay a Lower Rate

Use commitments, reservations, savings plans or eligible license benefits when utilization is predictable.

Reduce Software Cost

Verify whether BYOL, Azure Hybrid Benefit, SQL edition changes or a different RDS licensing model can reduce licensing cost without violating Microsoft terms.

Rightsize vCPU Carefully

Windows licensing often scales with cores or vCPUs.

An oversized VM can therefore increase both:

Compute cost + Software licensing cost

AWS explicitly documents this interaction through Optimize CPUs for eligible license-included Windows and SQL Server instances.

Schedule Development and Test Servers

If a Windows development server is used only during business hours, scheduling can reduce compute hours.

But make sure the provider actually releases the compute allocation.

Storage and backup may continue to bill.

Review SQL Server Edition

SQL Server Enterprise can cost significantly more than Standard or Web.

Do not deploy a higher edition unless the workload needs its capabilities and licensing model.

Review RDS Licensing

Count users and devices correctly.

Per-user licensing can fit employees who use several devices.

Per-device licensing can make more sense in shared-device environments.

Review Backup Retention

Thirty daily backups plus twelve monthly recovery points costs more than keeping only a few recent copies.

Retention should follow actual recovery and compliance requirements.

How Should You Compare Windows Cloud Providers?

Use the same workload specification.

A useful checklist is:

  1. Same vCPU and RAM
  2. Same Windows Server version
  3. Same region or India-location requirement
  4. Same persistent-disk capacity
  5. Same disk performance tier
  6. Same backup frequency
  7. Same retention period
  8. Same RDS user/device requirement
  9. Same SQL Server edition
  10. Same public-IP requirement
  11. Same expected egress
  12. Same support level
  13. Same commitment period
  14. Same tax assumptions
  15. Same availability/SLA requirement

Then compare:

Final Monthly TCO

not:

VM Price

Common Windows Cloud Pricing Mistakes

Avoid these common errors:

  • Comparing Windows and Linux VM prices as if they include the same software
  • Treating $0.046/vCPU-hour as a universal Windows license rate
  • Forgetting storage while the VM is stopped
  • Treating snapshots as a complete backup strategy
  • Assuming an existing Windows Server license can always be moved to the cloud
  • Ignoring RDS CALs for multi-user session workloads
  • Assuming SQL Server is included with Windows Server
  • Comparing one provider’s bundled storage against another provider’s compute-only VM
  • Ignoring egress and public-IP charges
  • Ignoring minimum software-license billing
  • Comparing USD list price without checking Indian tax treatment
  • Buying a reserved or committed plan before measuring utilization

The objective is not to find the lowest individual line item.

It is to avoid missing one.

FAQs

How much does a Windows cloud server cost in India?

There is no single price. The monthly total depends on vCPU, RAM, Windows licensing, storage, backup, network usage and any RDS or SQL Server requirements. Compare the complete workload configuration rather than only the VM price.

Why is a Windows VM more expensive than a Linux VM?

Windows Server normally adds a Microsoft software licensing component. Some providers bundle it into the VM price, while others expose it as a separate premium image or software surcharge.

How much does Google Cloud charge for a Windows Server image?

For most Compute Engine machine types, Google currently lists a Windows Server premium of $0.046 per visible vCPU per hour in addition to the underlying VM resources. Smaller legacy f1-micro and g1-small machine types use a different flat rate.

Is Windows Server licensing included in AWS EC2 pricing?

AWS publishes separate Windows Usage prices for EC2 and includes the applicable Windows Server licensing component in that rate. SQL Server images add further software licensing charges depending on the edition.

Can I use my existing Windows Server license in the cloud?

Possibly, but licensing rights depend on the agreement, license type, Software Assurance or subscription rights, cloud provider and tenancy model. Azure Hybrid Benefit is one explicit Microsoft program for eligible Windows Server licenses. Do not assume all existing licenses are portable to shared public-cloud VMs.

Do I need RDS CALs for Remote Desktop?

RDS CALs are generally required when users or devices access Windows Server Remote Desktop Services functionality. Limited administrative Remote Desktop access is treated differently. Hosting employee desktops or applications through RDS should be licensed according to Microsoft's current Product Terms.

Does SQL Server cost extra on a Windows VM?

Usually yes. Windows Server and SQL Server are separate products. SQL Server licensing depends on edition and cores or vCPUs, and can materially increase the monthly software cost.

Is backup included with a Windows cloud server?

Not automatically. Backup can be included in a bundled provider plan or billed separately based on protected capacity, retention and recovery points. Persistent disk and snapshots should also be checked separately.

Do Windows VMs stop billing when powered off?

Not always. On Azure, for example, a VM in the Stopped state still incurs compute charges, while Stopped (Deallocated) stops the VM compute charge. Disks and some networking resources can continue billing even after deallocation.

Does GST apply to cloud Windows servers in India?

GST treatment depends on the provider's billing entity, customer GSTIN and transaction structure. AWS India currently applies 18% GST to cloud services sold by AWS India, while Google Cloud's India treatment differs depending on contracting entity and GSTIN status. Verify the final invoice treatment before comparing providers.

Final Takeaway

Windows cloud pricing should not be reduced to a VM rate.

The real calculation is:

Compute + Windows + Storage + Backup + RDS + SQL + Networking + Support + Tax

For a simple IIS or .NET server, compute and the Windows license may dominate.

For a shared ERP environment, RDS can become important.

For a database server, SQL Server licensing and storage can outweigh the base VM.

For a backup-heavy workload, retention and recovery costs matter.

And for Indian buyers, billing currency and GST can change the final comparison.

Start with one normalized configuration, price every layer, and compare the complete monthly TCO.
